# KTS Text Solution — Android Studio

കെടിഎസ് ടെക്സ്റ്റ് സൊല്യൂഷൻ: ടെക്സ്റ്റ് വിഭജിക്കുക, എഡിറ്റ് ചെയ്യുക, തിരഞ്ഞെടുത്ത് കോപ്പി ചെയ്യുക. TalkBack-ന് പൂർണ്ണ പിന്തുണ.

## Android Studio-യിൽ തുറക്കുക

1. Android Studio (Koala / Ladybug അല്ലെങ്കിൽ പുതിയത്) തുറക്കുക.
2. **File → Open** — ഈ `KTSTextSolution` ഫോൾഡർ തിരഞ്ഞെടുക്കുക.
3. Gradle sync കഴിയട്ടെ. ആവശ്യമെങ്കിൽ IDE Gradle wrapper generate ചെയ്യും.
4. ഒരു ഫോൺ/എമുലേറ്റർ തിരഞ്ഞെടുത്ത് **Run**.

മിനിമം Android 8.0 (API 26). Kotlin + Jetpack Compose.

## പ്രവർത്തനം

- ആപ്പ് തുറക്കുമ്പോൾ ക്ലിപ്ബോർഡിലെ ടെക്സ്റ്റ് ഓട്ടോമാറ്റിക്കായി വരും.
- വെബ് പേജ് ലിങ്ക് എക്സ്ട്രാക്ഷൻ: ഒരു വെബ് പേജിന്റെ ലിങ്ക് (URL) കോപ്പി ചെയ്ത് ആപ്പ് തുറക്കുകയോ പേസ്റ്റ് ചെയ്യുകയോ ചെയ്താൽ, ആ വെബ് പേജിലെ മുഴുവൻ ടെക്സ്റ്റ് കണ്ടന്റും (പരസ്യങ്ങളും അനാവശ്യ മെനുകളും ഒഴിവാക്കി) വൃത്തിയായി ആപ്പിലേക്ക് പേസ്റ്റ് ചെയ്യപ്പെടും.
- മുകളിൽ: വായന, എഡിറ്റ്, തിരഞ്ഞെടുക്കൽ, ക്രമീകരണം ടാബുകൾ, കൂടാതെ ടെക്സ്റ്റ് കേൾക്കാനുള്ള പ്ലേ/സ്റ്റോപ്പ് (Play/Stop), ഫൈൻഡ് & റീപ്ലേസ് (Find & Replace), പേസ്റ്റ്, അൺഡൂ ബട്ടണുകൾ.
- ഫൈൻഡ് & റീപ്ലേസ്: ഏതെങ്കിലും വാക്ക് കണ്ടെത്തി 'റീപ്ലേസ്' (ഒന്ന് മാറ്റുക) അല്ലെങ്കിൽ 'റീപ്ലേസ് ഓൾ' (എല്ലാം മാറ്റുക) ചെയ്യാം. പഴയപടിയാക്കാൻ Undo ബട്ടൺ ഉപയോഗിക്കാം.
- താഴെ: ഖണ്ഡിക, വാക്യം, വാക്ക്, അക്ഷരം, കോപ്പി (ക്രമീകരണം ഒഴികെ എല്ലാ ടാബിലും).
- എഡിറ്റിൽ ടാപ്പ് = എഡിറ്റ് ബോക്സ്. ലോംഗ് പ്രസ് / TalkBack ഡബിൾ-ടാപ്പ്-ഹോൾഡ് = ഈ ഭാഗം കേൾക്കുക (Listen), ഡിലീറ്റ്, പുതിയ വിൻഡോ.
- സെലക്ഷൻ ടാബിൽ ഒന്നിൽക്കൂടുതൽ ഭാഗങ്ങൾ ഒന്നിച്ച് തിരഞ്ഞെടുക്കാം. ഡബിൾ-ടാപ്പ്-ഹോൾഡ് ചെയ്യുമ്പോൾ "തുടക്കം മുതൽ ഇതുവരെ", "ഇവിടെ നിന്നും ഒടുക്കം വരെ", "റേഞ്ച് സെലക്ഷൻ" ഓപ്ഷനുകൾ ലഭ്യമാണ്. മുകളിൽ സെലക്ട് ചെയ്തവയുടെ എണ്ണവും എല്ലാം സെലക്ട് ചെയ്യാനുള്ള ബട്ടണുകളും ഉണ്ട്.
- ക്രമീകരണത്തിൽ വായനാ വേഗത (Speech speed) മാറ്റാം.

## TalkBack

എല്ലാ ബട്ടണുകൾക്കും contentDescription ഉണ്ട്. ലോംഗ് പ്രസ് TalkBack-ൽ **double-tap and hold**. റേഞ്ച് സെലക്ഷനും കൂടുതൽ ആക്ഷനുകളും കസ്റ്റം ആക്ഷനുകളായി ലഭ്യമാണ്.
